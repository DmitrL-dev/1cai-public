Последняя опубликованная пара — Core dev19 / Companion 0.1.20. Основной маршрут
требует Windows x64 / CPython 3.11; отдельно опубликовано экспериментальное
Linux x86_64 дополнение: [state/history](product/PORTABLE-CORE.md) и
[Rust ZIP import](product/RUST-INPUT-CORE.md), без обещания полного Linux/macOS
product route. Текущие исходники содержат и более поздние эксперименты, которые
не входят в принятые пакеты. Границы задают [состояние поставки](product/READINESS.md),
[матрица поддержки](product/PLATFORM-SUPPORT.md) и [план](../ROADMAP.md).
Опубликованные файлы dev19 / 0.1.20 проверены по
[квитанции](product/evidence/release-dev19-publication-20261015.json);
[датированная сверка](product/RELEASE-PLAN-20261015.md) сохраняет историю этого выпуска.
Текущий [план полного финального релиза](product/FULL-FINAL-PLAN.md) ведёт
127 требований, все 24 IDE-сценария и очередь реализации;
[backlog](product/BACKLOG.md) классифицирует, чего не хватает каждой открытой строке.
[CI main `413cc65`](product/evidence/development-ci-413cc65-20261016.json)
подтвердил ограниченный installed Core/Companion workbench: первая фаза и restart
прошли в двух настоящих Windows Extension Hosts с проверкой байтов и cleanup.
Human GUI, native 1С и полная IDE этим не приняты. Исторические
[отказ `3cc29c2`](product/evidence/development-ci-3cc29c2-20261015.json) и
[ранний отказ `553e1fa`](product/evidence/development-ci-553e1fa-20261015.json) сохранены.
Ограниченный [Linux capture/source/graph блок](product/PORTABLE-CORE.md#linux-capture-и-чтение-снимков)
имеет [PR #102 source-приёмку](product/evidence/development-ci-366db69-20261016.json).
[PR #103 `c9cb31e`](product/evidence/development-ci-c9cb31e-20261016.json) и независимо
[fresh main `8e7346e`](product/evidence/development-ci-8e7346e-20261016.json)
проверили actual Linux installed CLI/MCP offline-комплект на синтетическом сценарии.
[Контракт комплекта](../scripts/release/OWNED-LINUX-KIT.md) связывает source, bytes
и отдельную `acceptance.json`; результаты старого комплекта не принимают новую сборку.
Это development-приёмка, опубликованные dev19 / 0.1.20 не меняются.

Новый [SNAP-DIFF-01](product/SNAPSHOT-DIFF.md) — source-контракт ограниченного
Linux paired CLI/MCP сравнения снимков и `rentgen_snapshot_diff`.
Общий budget действует на POSIX pair; Windows CLI остаётся прежним, новый MCP
добавляет общий deadline/output guard, public macOS закрыт. Старые CI `c9` / `8e`
новый diff не содержат; actual installed CLI/SDK-приёмка новой сборки нужна отдельно.
Exact-source CI PR #104 `c2b6cd2` (main `2d8254a`) проверил этот блок на синтетических
Linux/Windows fixtures; квитанция сохраняется отдельно.

Следующий source-контракт [TEST-RUN-QUAL-01](product/TEST-RUN-QUALIFICATION.md)
повторно сверяет retained YAxUnit artifacts с отчётом без запуска 1С; native-приёмка
настоящих pass/fail/crash/timeout/no-tests остаётся в backlog до стенда.
[Аудит плана выпуска](../scripts/release/RELEASE-PLAN-CONTRACT.md)
отделяет проверенные bytes и заявленное покрытие от ещё не принятого полного продукта.
Лицензированного стенда 1С/EDT пока нет, native-gates остаются открытыми.

## Просмотреть ZIP без установки редактора

[Локальная графическая рабочая область](product/LOCAL-GUI.md) входит в
экспериментальное дополнение dev19 для GNU/Linux x86_64: импорт Designer XML ZIP, поиск объектов,
полей и модулей, чтение исходников, сравнение двух ZIP и инвентарь трёх ZIP.
Она работает только с загруженными байтами, не создаёт снимок или черновик
и не применяет изменения. Установка описана в `INSTALL.md` финального
Linux-архива. Windows/macOS для этого маршрута не квалифицированы.
