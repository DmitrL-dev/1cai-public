# Проверка черновика платформой из редактора

Приёмка коммита `5c8acfa1` от 10 сентября 2026: companion 0.1.5 — сборка разработки для core
dev8. Опубликованная companion 0.1.4 и её контрольные суммы не изменены.

Контекстное меню выбранного черновика или исторической версии запускает
проверку полного `1cv8.exe`. Расширение повторно получает именно эту ревизию,
сверяет квитанцию, сохраняет предложение и UUID запуска в отдельном каталоге
профиля, затем вызывает локальный CLI. Новый head не подменяет выбранный снимок.
Путь и SHA256 клиента передаются ядру; оно проверяет их самостоятельно.

Получение результата выполняется отдельной командой без компиляции. Доступны
история текущего профиля и ввод UUID. Потерянный ответ не вызывает повтора;
`incomplete` не определяет состояние процесса, `PLATFORM_RUN_NOT_FOUND` не
доказывает, что запрос был принят ядром. Сохранённые файлы имеют локальное
происхождение без независимой аттестации.

Проверено:

- 159 Python-тестов и 29 Node-тестов, включая подмену ревизии/проекта,
  неверные ответы, потерю ответа, конкурентный запуск и отмену выбора.
- Настоящий установленный core dev8 + 1С 8.3.27.2342: два сохранённых
  синтетических черновика `40 + 3` и `40 + ;`. Первый проходит компиляцию,
  второй возвращает `diagnostics_present`; исходник в обоих случаях проходит.
- Сохранённые результаты читаются через сервис расширения. SQLite состояния
  и head неизменны после проверок.
- В VSCodium 1.135.06055 загружено содержимое собранного VSIX. Новый процесс
  редактора получил оба отчёта зарегистрированной командой, открыл JSON,
  проверил выбор версии по внутреннему идентификатору строки. Новых проверок
  и обращений к модели не было. Скрипт: `scripts/verification/companion_host/platform.cjs`.
- VSIX: SHA256 `c71b89397599d5102b778ad4ceee30137afa1708178f1c7c6b986da8a5e731ab`,
  131186 байт. В сборке нет npm-зависимостей; она восстанавливается из своих исходников.

Ограничения: диалог выбора EXE проверен контрактными тестами, а не ручным
нажатием в редакторе. Компиляция проверена через реальный сервис расширения;
в настоящем extension host проверено восстановление и отображение отчётов.
Функциональные тесты конфигурации, применение, EDT и расширения конфигурации
не входят в этот сценарий. Отмена целится в принадлежащее запросу дерево
Windows; аварийное завершение самого редактора не даёт гарантии остановки 1С.
На момент этой приёмки управляемая правка с Ollama была доступна только для
dev7. Её перенос на dev8 и найденный дефект качества модели описаны в
[проверке ежедневного сценария](DAILY-DEVELOPMENT-ACCEPTANCE.md).

CI собирает текущую версию разработки и отдельно восстанавливает принятую
0.1.4 из закреплённого коммита, сверяя исходную принятую контрольную сумму.
Тесты механизма выпуска используют собственную синтетическую запись приёмки,
чтобы изменение исходников разработки не подменяло доказательство старого выпуска.
