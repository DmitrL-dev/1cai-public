# Локальная проверка кандидата Core dev15 / Companion 0.1.15

28 сентября 2026, Владивосток. Исходный commit: `242ed98bf51bf4dd10dd925de093c3b83f7ce368`.
Работу и ревью выполнил основной агент без субагентов.

## Установка и сборки

Исправленные команды Core и MCP читают версию из `pyproject.toml` и требуют
точный wheel через `Resolve-Path -LiteralPath -ErrorAction Stop`. На собственном
wheel dev15 прошли обе установки в новых окружениях с путями, содержащими
пробелы. Все 103 рабочих файла совпали с wheel; `pip check` успешен. Настоящий
MCP-клиент получил 32 инструмента. Для обоих вариантов отсутствие wheel выбранной
версии привело к отказу до установки Core; wheel другой версии не был выбран.
Глобальные настройки принудительного прекращения ошибок в тесте не задавались.

Локальная сборка Core воспроизведена дважды; отдельно подтверждена офлайн-установка.
Проверены 40 файлов и 30 закреплённых зависимостей. 103 рабочих файла Core,
scanner и все dependency wheels совпали с dev14. Дельта wheel ограничена
метаданными версии; sdist содержит исправленные инструкции и обновлённые
версионные входы. Две сборки Companion дали одинаковый VSIX из 39 файлов.
Новые перечни совместимости сохраняют прежние версии и добавляют dev15.
Локальные контракты: 36 Python и 69 Node, без ошибок и пропусков.

## Установленный CLI

Сравнение снимков подтвердило добавление, удаление, изменение и неизменность
по одному файлу; три страницы, отказ неподходящего cursor и сохранность исходников,
head и базы. Отдельный observer подтвердил межпроцессный lock, восстановление
после завершения idle-процесса и отсутствие нового поколения при неизменных
исходниках. Модель не вызывалась. Эти результаты относятся к установленному
CLI и обычному observer; SCM проверяется отдельным сценарием.

## Редактор и установленная 1С

Свежий сценарий Companion 0.1.15 с установленным Core dev15 выполнен в отдельном
профиле VS Code 1.139.1, на 1С 8.3.27.2342 и YAxUnit 25.12. При актуальной
ревизии 2 выбрана сохранённая ревизия 1. Baseline дал один ожидаемый failure,
candidate прошёл тот же тест. Все 23 нативных шага завершились с кодом 0;
хеши JUnit и журналов сверены.

Второй процесс редактора после отключения профиля прочитал тот же результат
без нового тестового запуска. CLI повторно прочитал завершённую операцию;
новая операция получила `TEST_PROFILE_DISABLED`. Все 909 файлов завершённого
запуска, шесть исходных файлов, выбранная ревизия и head сохранились.
Модель не вызывалась. Снимки 2651 файла закреплённой копии редактора совпали;
103 файла установленного Core сохранились побайтно.

## Состояние кандидата

Эти доказательства относятся к локальному payload указанного commit. CI этого
кандидата, принятый CI ZIP, слияние и публичный выпуск dev15 ещё не квалифицированы.
После интеграции принятого SCM main нужно связать доказательства с окончательными
байтами и provenance. Локальный архив не подменяет артефакт принятого CI.

Испытан собственный синтетический проект: тестирование и восстановление результата
в редакторе. Типовые конфигурации, editor live apply, все системные библиотеки и
полная self-hosted готовность этим не подтверждаются. Production deployment
не выполнялся; независимое peer review не заявляется.
