# Правка из редактора и восстановление результата

2026-09-10. Companion 0.1.4 добавляет команду к модулю текущего снимка.
Используется принятый CLI-адаптер и установленный core dev7; три Python-файла
адаптера включаются в воспроизводимый VSIX. Чтение прежних dev4–dev7 сохраняется,
команда правки требует dev7.

Пользователь выбирает «Правка с локальной моделью» у модуля, вводит имя модели
и задачу. По умолчанию предлагается проверенная qwen3.5:9b без рассуждения.
Рентген создаёт каталог запуска в профиле, пишет туда вход и запускает
упакованный адаптер. SourceRef берётся только из выданного деревом непрозрачного
идентификатора. Параллельные старты в одном экземпляре расширения запрещены.
Штатное уведомление прогресса позволяет остановить собственное дерево процессов.

После завершения читается квитанция записи через новый CLI-вызов; открывается
diff именно этой ревизии. Результат BSL показан отдельно от бизнес-корректности:
тесты 1С не запускались, исходная конфигурация не менялась. Сообщение модели
не считается доказательством. Диагностический отчёт остаётся неподписанным
результатом локального запуска и не разрешает применение.

Команда «Проверить результат правки» предлагает недавние каталоги этого профиля.
Она читает намерения из журнала и запрашивает исходные operation_id через
`draft-receipt`. После остановки/потери ответа новых мутаций нет. При наличии
квитанции открывается сохранённая ревизия; отсутствие квитанции или повреждённый
журнал показываются как неопределённый результат. Завершённость процесса не
приравнивается к отсутствию записи. Все читаемые файлы и списки ограничены
по размеру, пути выбираются только из каталога запусков данного профиля.

Реализация: `repair.cjs` отвечает за каталоги, процесс и сверку квитанций;
`repair-ui.cjs` — за ввод, прогресс и команды. `views.cjs` выдаёт выбранный
SourceRef и открывает подтверждённую ревизию штатным diff; `core.cjs` добавляет
только чтение квитанции. Прежние сценарии чтения сохраняются.

Проверки: контракты для чужого проекта/подменённой квитанции, потеря ответа
после записи без повторной мутации, неполный журнал, повторный старт, отмена;
упаковка точных Python-файлов; настоящий установленный companion в VSCodium,
один реальный модельный прогон, diff, независимое чтение/BSL и повторное открытие
результата в новой сессии. Автоматизация команды может передавать текст и модель
явно, но всегда использует настоящий выданный деревом идентификатор модуля.
Изоляция от других расширений того же редактора не заявляется.
