# Локальный агент: измерение первого сценария

2026-09-09. Это диагностический замер на искусственной правке50байт, не benchmark
качества 1С и не основание для заявления о превосходстве продукта.

Базовый сценарий VS Code1.127.0 / Cline4.1.17 legacy / Ollama qwen3.5:9b:
пять модельных запросов,231секунда от начала до завершения задачи. Финальные
метрики пяти ответов `/api/chat` из лога настоящего Cline дают:

| Метрика | Сумма |
|---|---:|
| Время Ollama total_duration | 217,88сек |
| Обработка входного контекста | 31,53сек |
| Генерация ответа | 184,50сек |
| Сгенерировано токенов (включая reasoning) | 2399 |
| Скорость генерации | около13токенов/сек |
| Входной контекст на запрос | 23 960–26 807токенов |

Контекст окна32768 выбран профилем явно. Во время отдельной проверки VSCodium
на той же машине `/api/ps` сообщил model size10 521 741 216байт,
size_vram6 552 925 952байт. `nvidia-smi` определил RTX4060 /8188MiB, в тот
момент занято7490MiB. Модель размещена в GPU лишь частично; это вероятный
источник низкой скорости генерации. Эти показатели не доказывают долю каждого
аппаратного ограничения и не являются причинным сравнением двух настроек.

В поставленном legacy bundle OllamaHandler передаёт model/messages/stream,
options.num_ctx и tools. Параметр `think` отсутствует. Добавление произвольного
поля настройки Cline не считается его поддержкой. Прямая правка сжатого VSIX
ради одной проверки нарушила бы воспроизводимость выбранного upstream adapter.

Не следует сокращать окно до16K при фактическом входе24–27K: потеря инструкций
и аргументов не является ускорением рабочего сценария. Не следует считать
отключение reasoning доказанным улучшением качества сложных задач 1С.

Дальнейшие варианты требуют измерения на одинаковых задачах: модель, которая
помещается в GPU целиком; корректная передача выбранного режима reasoning;
более короткие MCP-аргументы при сохранении точного snapshot, полномочий,
CAS и квитанций. Полные SourceRef с повторяющимися UUID/SHA полезны как
каноническое доказательство, но дороги при генерации моделью. Формат ввода
можно пересмотреть отдельно от сохранённого канонического доказательства.

Источники метрик: `output/editor-cline-acceptance-20260909/profile3/ollama-metrics.json`
и собственное чтение локального runtime. Определения полей:
[Ollama chat API](https://docs.ollama.com/api/chat),
[thinking](https://docs.ollama.com/capabilities/thinking).

## Проверка полностью открытого редактора и компактной модели

Официальный архив VSCodium1.135.06055/Windows x64 проверен по SHA256
`0bec978f201238624bc9ad43966f5e201ed8afacc37d77035a822252d9c9c200`;
MIT license сохранена. Cline4.1.17 установлен из прежнего проверенного VSIX,
движок явно закреплён как legacy. Ядро — прежний установленный dev3, сборка
и уже пройденные core/Java suites не повторялись.

Первый запуск qwen3.5:9b в VSCodium завершился по пределу240секунд: четыре
успешных вызова head/source-list/draft-start/draft-read, команда edit осталась
частичной. После закрытия редактора независимый CLI нашёл только ревизию1.
Отчёт `open-codium-qwen9b.json` сохраняет этот отказ, без утверждения об успехе.

Далее установлен qwen3.5:4b (GGUF Q4_K_M, фактически4,7B параметров),
Ollama digest `2a654d98e6fba55d452b7043684e9b57a947e393bbffa62485a7aac05ee4eefd`.
[Карточка разработчика](https://huggingface.co/Qwen/Qwen3.5-4B) указывает Apache-2.0;
проверена metadata revision `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`.
[Ollama-вариант](https://ollama.com/library/qwen3.5:4b) загружен штатным pull,
без облачного аккаунта или платных запросов.

Новый профиль использовал **тот же проект, снимок, исходные байты, окно32768
и задание**, новые IDs операций/черновика. Настройки reasoning не изменялись.
Пять модельных запросов завершились за88,1секунды. Выполнены head/source-list/
draft-start/draft-edit. Новый CLI подтвердил две точные ревизии, совпадение
обеих квитанций с журналом MCP, неизменность исходника/head. Кандидат:
`df29aaf0804f4b409d3dba08e957bc76bc98935aee29291265f288c79c379399`.

| Метрика4B | Значение |
|---|---:|
| Runtime size / size_vram | 7 106 172 928 / 7 106 172 928байт |
| Входной контекст | 24 086–26 967токенов |
| Сумма Ollama total_duration | 74,99сек |
| Обработка входа | 18,35сек |

Модель целиком размещена в GPU; контекст не обрезался ради ускорения.
Варианты отличаются размером модели, аппаратным размещением и решением агента
о дополнительном чтении, поэтому это не изолированное измерение одной причины.
Один маленький сценарий не доказывает качество сложных доработок или SLA.
Следующая приёмка должна включать реальную диагностику, более содержательные
задачи и удобное чтение/сравнение модулей из редактора.

Машинный отчёт: `C:/1cAI/output/product-readiness-2026-09-08/open-codium-qwen4b.json`.
Самостоятельный verifier `scripts/verification/verify_open_editor_draft.py`
проверил успешный прежний запуск VS Code (rev2) и отказ VSCodium9B (rev1)
перед новой проверкой4B. Завершение редактора с0 само по себе не даёт pass.
