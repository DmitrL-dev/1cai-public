## Что уже имеет хорошую основу

- Источник истины находится в локальном core: проект, права, снимки, черновики,
  MCP и квитанции не делегируют контроль модели.
- Операции привязаны к snapshot/commit, ожидаемой ревизии и хэшам; конфликт и
  потеря ответа переводятся в явный результат, а повторная запись не делается
  автоматически.
- Metadata preview строит два полных diff и связывает candidate с сохранённым
  бизнес- и платформенным доказательством. Preflight apply проверяет свежесть,
  права и живые байты, но запись пока запрещена.
- Observer хранит Git-находки, события и квитанции транзакционно; replay,
  resolve и reopen переживают перезапуск. Bounded watcher повторно проверяет
  HEAD перед публикацией.
- Публичная поставка собирается офлайн, имеет MIT-лицензию, фиксированные
  хэши и явные ограничения. Основная рыночная позиция описана в
  [COMPETITOR-MATRIX.md](COMPETITOR-MATRIX.md).

## Архитектурные решения

Граница ядра выбрана правильно для открытого продукта: модель является источником
предложения, а не полномочий; платформа 1С, BSL и тесты дают отдельные receipts.
SQLite и файловые хэши подходят для локального self-hosted профиля, если размеры,
срок хранения и восстановление после сбоя остаются явными.

Главный риск — преждевременно назвать orchestration API автономным агентом.
Сейчас watcher — синхронный адаптер одного прохода, а metadata gate — read-only
квалификация. В документации и README это должно оставаться видимым до появления
реального writer, scheduler и analyzer adapters. Любой новый внешний процесс
должен получать project/snapshot binding и проходить повторную авторизацию перед
публикацией результата.

## Выбранное направление

Рентген позиционируется как полностью открытый MIT/self-hosted control plane
проверяемой разработки 1С. Существующие IDE, BSL LS, SonarQube, Vanessa, EDT MCP
и модели подключаются адаптерами. Собственная ценность — evidence-first lifecycle:
изменение, проверка, сохранение доработок при обновлении, постоянный аудит и
отчёт владельцу с источником каждой метрики. Это направление не требует
закрывать экосистему и позволяет подключить Spectorn как защищённый маршрут,
когда его локальный контракт будет принят.
