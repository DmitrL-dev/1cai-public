# Рынок инструментов 1С и направление Рентгена

Срез проверен 15 сентября 2026 года по первичным источникам: официальным
страницам продуктов, документации, условиям поставки и репозиториям авторов.
Это карта выбранных решений русскоязычного рынка, а не полный реестр.
Все ссылки в таблице проверены на эту дату; цены и условия относятся к ней.

Независимо проверены публикация исходников/лицензий и содержание указанных
страниц. Продукты не устанавливались и сравнительные испытания не проводились:
функциональные возможности ниже — заявления поставщика или автора проекта.
«Не подтверждено» означает отсутствие подтверждения в просмотренных источниках,
а не доказанное отсутствие функции. Публичный репозиторий и бесплатная загрузка
сами по себе не означают открытую лицензию всей поставки.

Ближайшие решения для предметного сравнения — bsl-ai-toolkit, Unica, EDT-MCP,
MCP:RSV и Confaster. Открытость, headless-работа, локальность, независимость от
модели, dry-run, Git/откат и перенос доработок по отдельности уже представлены.
В просмотренных источниках не подтверждён весь единый процесс
«immutable snapshot → permission → receipt → owner audit / update» у одного
решения. Это гипотеза для сравнительных испытаний, а не заявление «аналогов нет».

## Вывод для позиционирования

Ставка Рентгена — **единый открытый процесс проверяемой разработки, аудита и
обновления 1С: immutable snapshot → permission → receipt → owner audit / update**.
Отличие нужно доказывать целостностью этого процесса на реальных проектах;
MIT, self-hosted, headless и model-agnostic по отдельности уже не уникальны.
Следующие пункты задают продуктовую цель; готовность текущей ветки отделена
в разделе «Что обещаем пользователю сейчас».

1. **Открытая и управляемая поставка.** MIT и self-hosted по умолчанию,
   локальная модель или совместимый upstream, адаптеры без привязки к одному
   провайдеру. Это необходимые свойства поставки, а не самостоятельное
   доказательство конкурентного отличия; Spectorn route входит в целевой процесс.
2. **Evidence-first.** Каждая операция получает immutable input, exact
   snapshot/commit, права, хэши, журналы, platform/BSL/test receipts и
   понятный исход passed/diagnostics/failed/incomplete. Текст модели не
   является доказательством.
3. **Headless metadata и обновления в том же процессе.** Связать изменение
   metadata/forms/СКД и перенос доработок с конкретными входами, разрешением,
   результатами платформенной проверки и границей отката. При stale input,
   отзыве разрешения или неоднозначном конфликте остановиться без blind retry.
   Само наличие headless CLI, round-trip или three-way merge уже не уникально.
4. **Непрерывный аудит.** Git watcher и scheduler анализируют только новый
   clean commit, связывают findings с кодом и snapshot, показывают новые,
   исправленные и повторно открытые нарушения, а владельцу дают отчёт с
   источником каждой метрики и ссылками на тот же snapshot и receipts.
5. **Интеграция вместо изоляции.** BSL LS, SonarQube, Vanessa, YAxUnit,
   1C:EDT MCP и локальные/облачные модели подключаются адаптерами. Открытые
   проекты получают контрибьюции обратно, а не закрытый форк.

## Приоритеты

| Приоритет | Результат | Критерий выхода |
| --- | --- | --- |
| P0 | Metadata apply/undo на рабочей копии | Трёхфазный журнал intent → write → re-read, stale/revoke/conflict/recovery, round-trip на реальной 1С, без blind retry |
| P0 | Git watcher + поставляемые adapters BSL/других анализаторов | Новый commit анализируется один раз, результат привязан к exact tree, сбой повторяется безопасно, history переживает restart; native ServiceMain boundary добавлена, live service deployment ещё впереди |
| P0 | Spectorn route | Зафиксирован весь маршрут upstream, policy при недоступности и отсутствие обхода защиты; secret не попадает в логи |
| P1 | Обновление конфигурации | Three-way merge базовой/текущей/новой конфигураций, конфликт на уровне object/UUID/BSL, тестовая база и откат |
| P1 | Владелец продукта | Версионируемый отчёт по quality, тестам, изменениям, рискам и источникам; бизнес-метрики только из подтверждённых runtime-данных |
| P2 | Совместимость и экосистема | Матрица 8.3.x/EDT/типовых конфигураций, .cf/.cfe и EDT XML, расширения, forms/СКД, MCP/editor UI |

## Что обещаем пользователю сейчас

Текущая ветка уже содержит открытое ядро snapshots/drafts/MCP, durable
observer findings, bounded Git watcher и read-only metadata qualification.
Живое metadata apply/undo, автоматический scheduler, поставляемый
репозиторный analyzer, обновление типовых конфигураций и Spectorn route пока
не объявляются готовыми. Это разделение должно оставаться видимым на стартовой
странице и в каждом release note.
