# План проверки свежего EDT preview

1. В отдельной ветке сохранить дизайн и привязать входной собственный EDT
   профиль к точному snapshot, включённому runtime и исходному inventory.
2. Добавить verifier, который через установленный Core dev10 создаёт новый
   EDT preview и читает обратно его закрытый retained run.
3. Выполнить preflight/live apply на зарегистрированном источнике; закрепить
   файлы на время импорта в новую 1С базу и structural round-trip.
4. Выполнить CAS undo, проверить полный исходный inventory и отдельный
   YAxUnit бизнес-прогон на точных inventory нового preview.
5. Сохранить публичную краткую квитанцию без частных путей; обновить product
   readiness и документацию ограничений.
6. Проверить скрипт и writer tests, провести независимое ревью, затем PR,
   обе проверки CI, merge, подробное дополнение GitHub Release и анонс.
