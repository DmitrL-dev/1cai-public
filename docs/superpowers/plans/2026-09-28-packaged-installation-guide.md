# План исправления поставляемых инструкций

Основание: [дизайн](../specs/2026-09-28-packaged-installation-guide-design.md).
Исполнитель один, без субагентов. Существующее поручение разрешает исправления,
проверку и выпуск. Для этой ошибки дополнительное решение владельца не требуется.

1. Воспроизвести старую команду на wheel dev14 в новом окружении; сохранить отказ.
2. Исправить два документа; выполнить скопированные из них Core/MCP-команды.
3. Проверить CLI, версию, 103 установленных файла, pip check, 32 MCP-инструмента
   и отказ при отсутствии точного wheel. Сохранить квитанции с SHA256.
4. Ревью diff, локальный commit; дождаться квалификации и слияния PR38.
5. Включить исправление в следующий кандидат Core с новой версией и нужной
   проверенной совместимостью Companion; квалифицировать CI/пакеты/новый main.
6. Опубликовать новый выпуск с подробным GitHub-анонсом. Старые assets не заменять.

## Состояние

Подготовка исправления идёт в отдельном свободном checkout, основанном на
квалифицированном main 6b775db. PR38 и его CI не изменяются этой работой.

## Выполнено локально

Старая команда воспроизвела отсутствие wheel dev13 при исходниках/wheel dev14.
Новые блоки Core/MCP выполнились в свежих папках с пробелами: pip check успешен,
версия dev14 подтверждена, по 103 установленных файла совпали с принятым wheel.
Два отрицательных случая с отсутствующим точным wheel остановились на Resolve-Path
до установки Core. Проверочный harness не задавал ErrorActionPreference.
Установленный MCP прошёл существующий клиент с 32 инструментами; для startup
использованы собственные registry/scanner вместо примерных C:\ путей.
[Квитанция](../../product/evidence/packaged-installation-guide-20260928.json).

Это проверка инструкций на принятом payload dev14. Новая поставка изменённого
sdist ещё не собрана и не принята; после изменения версии проверка повторяется.
