# Core dev15 / Companion 0.1.15: план выпуска

Причина выпуска — исправленные поставляемые инструкции установки выбранной
версии Core. Два документа входят в sdist, поэтому их доставка требует нового
квалифицированного пакета. Старые теги/assets не заменяются. Работа и ревью
выполняются одним агентом; production deployment требует отдельного решения.

## Состав

Core dev15 включает команды, читающие project.version, точный LiteralPath,
явный отказ при отсутствии wheel и закреплённый MCP-профиль. Companion 0.1.15
добавляет явную совместимость с dev15 в существующие перечни. Прежние версии
сохраняются, неизвестные версии отклоняются. Обновляются текущие profile/delivery
fixtures и пути CI; исторические доказательства не получают новый номер версии.

## Границы

Номер версии и локальные контракты сами по себе не означают принятие выпуска.
Результаты dev14 не называются нативным прогоном dev15. Полная self-hosted
готовность, типовые конфигурации, protected model route и бизнес-метрики остаются
отдельными требованиями. Независимое ревью не заявляется при работе без субагентов.

## Локальная совместимость

До добавления dev15 рабочие списки отказали: Python — 1 failure / 1 pass,
Node — 2 failures на новых случаях. После изменения 36 Python и 69 Node прошли
без ошибок и пропусков. Перечни изменены только добавлением dev15; старые
версии сохранены. Выпуск, нативный редактор dev15 и SCM ещё не квалифицированы.
