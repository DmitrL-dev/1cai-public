# План нативной проверки dev10

1. В отдельной ветке зафиксировать метод и критерии в design doc.
2. Добавить воспроизводимый verifier в `scripts/verification/`: создать
   проект и retained preview через установленный Core dev10, выполнить
   preflight/apply и сравнить полный inventory с candidate.
3. Загрузить изменённый live source в новую файловую базу через 1С,
   проверить компиляцию и обратную выгрузку.
4. Выполнить CAS undo и проверить полное побайтовое восстановление. Для
   сохранённого preview выполнить существующий YAxUnit verifier, сверить
   его source inventories с результатом live writer.
5. Сохранить короткий доказательный JSON и обновить readiness-документацию
   с точными пределами проверки.
6. Выполнить узкие тесты Core writer и нативный verifier; проверить отчёт,
   затем независимое ревью, PR, CI, merge и подробный релиз/анонс в GitHub.
