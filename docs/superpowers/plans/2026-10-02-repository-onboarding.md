# План оформления репозитория «Рентгена»

**Цель:** понятное первое знакомство и законченный маршрут до первого снимка.

**Структура:** главная страница ведёт к первому запуску и пользовательскому
руководству. Каталог документации и подробные ограничения доступны отдельно.
Визуальный слой состоит из статических SVG с текстовым эквивалентом.

**Формат:** Markdown и SVG; исходники продукта не меняются.

## Ограничения

- Язык: русский. Mermaid не используется.
- Только документация и визуальные исходники в выделенной рабочей копии.
- Версии и приёмка подтверждаются Source/существующими отчётами.
- Модель, продукт и тяжёлые рендереры в этом задании не запускаются.
- Проверку в браузере, Git и публикацию выполняет основной агент.
