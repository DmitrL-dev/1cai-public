# Оформление репозитория для первого знакомства

Дата: 2 октября 2026. Основание: явная просьба пользователя сделать
репозиторий Рентгена понятнее, структурированнее и визуально выразительнее
для неискушённых читателей, с большой цветной схемой без Mermaid.

Исходный срез: `fe75f6950711de7f4df63067fbdf6872890a9d6a`.
Изолированная ветка: `codex/repo-clarity-20261002`.

## Выбранный подход

Рассмотрены три подхода: расширить справочник на главной, добавить
витрину отдельных функций или выстроить маршрут знакомства. Выбран маршрут
**«понять → попробовать → углубиться»**. Он даёт читателю первое действие
и наблюдаемый результат, сохраняя подробные контракты в каталоге документации.

Обложка стала компактнее. Главная схема показывает отношения между исходниками,
снимком, черновиком и проверяемой ревизией, возврат к доработке и отдельное
решение о применении. Новая страница первого знакомства объясняет подготовку,
термины и выбор задачи до чтения команд.

## Правила содержания

- Опубликованные Core dev15 / Companion 0.1.15 явно отделены от
  кандидатов Core dev16 / Companion 0.1.17.
- Первый результат — снимок и список модулей. При готовой выгрузке
  для него не требуются модель и установленная платформа 1С.
- AI, BSL, платформа и тесты подключаются по выбранному сценарию;
  их требования не скрыты.
- Сохранение рабочей копии, сохранение ревизии и применение описаны
  самостоятельными действиями.
- Исторические native-опыты относятся к своим версиям. Общая готовность,
  типовые конфигурации и качество AI на произвольных задачах не объявлены принятыми.
- Названия панелей и команд сверены с `integrations/vscode-rentgen/package.json`;
  команды поиска и анализа связей — с `rentgen_core/cli.py`.
- Программный код, зависимости, поставки, workflow и исходные доказательства
  приёмки в этом оформлении не изменяются.

## Визуальные решения

SVG редактируются как текст и используют системные шрифты. Цвета этапов
согласованы между рисунками; номера, заголовки и стрелки сохраняют смысл
без распознавания цвета. Иллюстрации не изображают интерфейс продукта.

В SVG присутствуют `title`, `desc` и связь `aria-labelledby`.
В Markdown есть описания картинок, ссылки на полный размер и текстовый
эквивалент маршрута. Непрозрачные фоны рисунков сохраняют контраст
при светлой и тёмной теме страницы GitHub.

## Уточнения после проверки новичком

По итогам независимого просмотра внесены пять точечных уточнений:

- В первом запуске отдельно описаны опубликованный Companion 0.1.15
  с профилем из соответствующего тега и сборка кандидата 0.1.17
  из текущих исходников. Установка скачанного VSIX относится к профилю 0.1.15.
- Сообщение `recovery` в stderr объяснено как служебная запись
  перед захватом. Оно возможно при успехе; итог определяется ответом и кодом.
- В Markdown и схеме первый ручной черновик направлен к
  `proposal-create` / `draft-save`. Рабочая копия редактора относится
  к дальнейшей доработке существующего черновика.
- Для палитры команд указан Ctrl+Shift+P, а названия действий
  совпадают с полными UI-названиями Companion.
- Сокращённые JSON показывают точные пути `result.project_id`
  и `result.snapshot.snapshot_id`; примеры ID не предлагается подставлять.

Факты сверены чтением `prepare.py`, `install.ps1`, `package.json`,
CLI, публикации снимка и исходников тега `companion-v0.1.15`.
Продукт для этих уточнений не запускался.

## Проверка

- Проверяются локальные пути и якоря новых и изменённых Markdown.
- Проверяется XML трёх SVG, идентификаторы, размеры и отсутствие
  скриптов, обработчиков событий и внешних ресурсов.
- Для визуального осмотра используются временные PNG из имеющегося
  в рабочей среде Sharp; установка пакетов не требуется.
- Временные растровые превью удаляются после осмотра. Источники — SVG.
- Продукт, runtime, модели и нативные службы в этом задании не запускаются.
  Проверки оформления не являются приёмкой новой поставки.
- Git, окончательный просмотр и публикацию выполняет основной агент.

Результат узкой проверки после уточнений: шесть Markdown, 211 локальных ссылок и якорей,
три SVG; отсутствующие пути, якоря и ошибки XML не найдены.
`git diff --check` завершился без замечаний. Растровые превью осмотрены:
кириллица отображается, текст помещается в карточки, номера и стрелки
задают последовательность. Фактический рендер GitHub в разных темах
и на мобильном устройстве здесь не проверялся; для небольшого экрана
даны текстовый маршрут и ссылка на полный размер.
Два сокращённых JSON-примера разобраны как JSON; расположение полей и
формат ID сверены с CLI. Обновлённые подписи главной схемы повторно
отрендерены и осмотрены без уменьшения размера текста.

## Черновик подробного GitHub-анонса

**Название:** Понятный вход в Рентген: выбор маршрута, путеводитель и большая схема одной правки.

В репозитории обновлено первое знакомство с Рентгеном. Главная страница
коротко объясняет, как работать с исходниками 1С, и ведёт читателя по его
ближайшей задаче: понять инструмент, сделать первый запуск, освоить редактор
или оценить возможности для команды.

Новая страница «Первое знакомство» помогает подготовиться без чтения
технического справочника подряд. В ней есть маршрут по роли, список
подготовки по выбранной задаче, признаки успешной установки,
объяснение мест хранения и словарь названий Core, Companion, scanner,
VSCodium, Cline, Ollama, MCP, BSL и YAxUnit.

Большая цветная схема показывает весь путь одной правки:
выгрузка → снимок → чтение модуля → отдельный черновик →
сравнение и проверки → решение человека. На ней видно,
где можно готовить предложение вручную или с AI и как замечания
возвращают к новой ревизии. Применение вынесено в самостоятельный выбор.
Первый ручной черновик создаётся командами ядра;
рабочая копия редактора служит для доработки уже существующего.

Схема хранения объясняет различие между Ctrl+S, сохранением новой
ревизии в ядре и отдельной операцией применения к исходному файлу.
В руководстве добавлен пример: результат проверки ревизии 1
не подтверждает текст, сохранённый ревизией 2.

Каталог документации сохраняет точные инструкции по установке,
MCP, черновикам, платформе, тестам, применению, наблюдению
и EDT. Разделы получили понятные русские названия и быстрые переходы.

Первый законченный результат остаётся небольшим: установить Core,
зарегистрировать папку выгрузки, создать снимок и получить пути модулей.
Если выгрузка уже подготовлена, модель и установленная платформа 1С
для этого шага не требуются.

Версии и степень готовности обозначены явно. Последняя опубликованная
пара раннего доступа — Core dev15 / Companion 0.1.15.
Core dev16 / Companion 0.1.17 в текущих исходниках остаются кандидатами.
Оформление не квалифицирует новую поставку, ежедневный нативный цикл,
типовые конфигурации или качество AI на произвольных задачах.

Локальные ссылки, XML и растровые превью схем проверены отдельно от продукта.
Рисунки доступны как редактируемые SVG; Mermaid и внешние шрифты
не используются. Программный код, зависимости и версии пакетов
в этом изменении не менялись.
