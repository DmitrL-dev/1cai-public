# Рентген core 0.1.0.dev7 — ранний доступ

Локальное открытое ядро для снимков конфигурации, графа зависимостей,
черновиков с историей, BSL-диагностики и stdio MCP. Windows x64 / Python 3.11.

В ZIP: wheel, исходники, Go scanner, офлайн-зависимости MCP, лицензии и хэши.
Собственный код MIT. Python, редактор, Java/BSL-LS, модель и платформа 1С
устанавливаются отдельно.

Публичные исходники воспроизводят принятый wheel и sdist побайтно. Подтверждены
сборка и установка wheel в чистое окружение; публичный набор включает проверки
публикации снимков, доступа, чтения источников и операций CLI.

Установка: [GETTING_STARTED.md](https://github.com/DmitrL-dev/1cai-public/blob/core-v0.1.0-dev7/GETTING_STARTED.md).
Работа с редактором требует отдельного companion и подготовленного профиля.

Применение изменений к живой конфигурации, обновления и сквозные проверки
с реальной платформой 1С ещё не приняты. Этот prerelease не обозначает
полную готовность продукта.
