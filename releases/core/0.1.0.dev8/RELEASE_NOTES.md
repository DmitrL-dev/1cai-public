# Рентген core 0.1.0.dev8 — ранний доступ

Сравнение снимков и локальный observer теперь доступны в офлайн-комплекте.
Observer сохраняет отчёты об изменении выгрузки без запросов к модели.
Предложения можно проверить компилятором установленной 1С на отдельной базе
и выполнить через заранее зарегистрированный профиль YAxUnit.
Историческая версия черновика и завершённый отчёт сохраняются независимо
от последующих правок; чтение результата не повторяет запуск платформы.

Нативные процессы принадлежат Windows Job Object. Один проект допускает
одну нативную проверку одновременно; контролируются расход диска и завершение
дочерних процессов. После успешных тестов очищаются два служебных каталога
ibcmd; тестовые базы и отчёты сохраняются.

Комплект: Windows x64 / CPython 3.11, ядро, исходники, scanner, 30 wheels
зависимостей MCP, лицензии и контрольные суммы. Python и платформа 1С
устанавливаются отдельно. Для редактора используйте companion 0.1.8.
Профиль YAxUnit требует отдельного доверенного CFE; он не включён в архив.

Проверено: две одинаковые сборки CI, независимая офлайн-установка скачанного
артефакта и 21 инструмент MCP. Все 50 Python-модулей поставки совпали с
принятым исходным коммитом. На 1С 8.3.27.2342 ранее приняты синтетические
проверки корректного/ошибочного кода и fail/pass YAxUnit для этих исходников.

Ограничения: один слой Designer XML для платформенной проверки, один
синтетический профиль тестов, нет полной приёмки на типовых конфигурациях.
Контроль диска программный, запуск BSL не изолирован от ОС. Длительное
хранение баз требует управления пользователем. Применение конфигурации,
типовые обновления, бизнес-метрики и интеграция Spectorn не объявлены готовыми.

Тег указывает на коммит сборки `a1e33318eb1cbb3909f8c3e2b7d296e2cb0212af`.
Манифест выпуска зафиксирован последующим коммитом и приложен к выпуску:
он подтверждает уже собранные байты без изменения исходного тега.
Существующие версии и их файлы не заменяются.
