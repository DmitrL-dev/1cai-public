# Рентген Companion 0.1.12 — совместимость с Core dev12

Предварительный выпуск расширения VSCodium/VS Code для установленного
`rentgen-core 0.1.0.dev12`.

## Что изменилось

- Профиль и команды редактора принимают точную версию Core `0.1.0.dev12`.
  Поддержка ранее принятых dev4–dev11 сохранена. Неизвестный dev13 отклоняется.
- Новая версия применяется к чтению проекта и черновиков, BSL-анализу,
  тестированию, платформенной проверке и управляемому ремонту. Проверки
  выбранного Python, registry и project ID продолжают действовать.
- Генератор обычного профиля принимает dev12 и записывает фактическую версию
  выбранного установленного Core. Проверочные генераторы тестового профиля
  используют dev12. Подготовка профиля проверяет Windows, Python 3.11 и
  требуемые версии установленного Core/MCP.
  Установщик BSL runtime принимает dev12; его известный перемежающийся отказ
  холодной установки не исправлен этим изменением.
- Документация установки обновлена для новой пары версий. Автоматической
  замены Python или перезаписи существующего профиля нет.

## Установка и границы

Установите проверенный Core dev12 и VSIX, затем создайте отдельный профиль по
[инструкции](https://github.com/DmitrL-dev/1cai-public/blob/main/integrations/open-editor/README.md).
Один VSIX без профиля не подключает проект. Существующий профиль сохраняет
свой Python; переключение выполняется явно.

Новая причина отказа Git-аудита относится к локальному журналу службы Core.
Companion не добавляет отдельный экран этой диагностики. Подробности и пример
журнала приведены в [выпуске Core dev12](https://github.com/DmitrL-dev/1cai-public/releases/tag/core-v0.1.0-dev12).

Нативная проверка нового VSIX в связке «редактор → Core → 1С» этим выпуском
не заявляется. Исторические результаты dev11/Companion 0.1.11 остаются
историческими. Типовые конфигурации, живая рабочая ИБ и production deployment
требуют отдельной приёмки. [Issue #23](https://github.com/DmitrL-dev/1cai-public/issues/23)
о холодной установке и [issue #25](https://github.com/DmitrL-dev/1cai-public/issues/25)
о редком CI timeout остаются открытыми.
