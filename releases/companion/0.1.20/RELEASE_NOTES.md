# Рентген Companion 0.1.20



Предварительный выпуск расширения для Windows-маршрута с Core **0.1.0.dev19**.
Готовность полного продукта, IDE, native 1С или AI этим компонентом не заявлена.

## Изменения после 0.1.18

- Первый ручной черновик можно начать из сохранённого модуля командой
  **«Рентген: создать ручной черновик модуля»**. Открытие рабочей копии само
  по себе не сохраняет новую ревизию; для этого нужна отдельная команда
  **«Рентген: сохранить версию черновика»**. Модель для ручной правки не нужна.
- Сохранение связывает текст с выбранными source/snapshot и ожидаемой ревизией,
  сохраняет контекст и operation ID для чтения квитанции после потери ответа.
  Посторонние изменения не перезаписываются автоматически; устаревшее повторное
  изменение должно отказать, сохранив локальную работу.
- Новые Core CLI `draft-start` / `draft-edit` позволяют начать черновик и
  сделать точную ограниченную замену из отдельного клиента с теми же
  проверками ревизии и квитанциями. История не становится записью в исходники.
- Поздний результат BSL, платформенной или функциональной проверки не должен
  показываться как результат уже изменившегося/закрытого контекста черновика.
- Совместимость с Core dev19 добавлена явно в Companion и генератор профиля;
  неизвестная будущая версия не допускается автоматически.

Деревья модулей и черновиков, история, diff и восстановление результатов
сохраняют прежний смысл. Просмотр, сохранение и успешная проверка не разрешают
применение к рабочей базе или файлам выгрузки.

## Установка точной пары

1. Установите Core dev19 из `rentgen-core-0.1.0.dev19-windows-py311.zip`
   по его release notes, проверьте manifest/SHA-256 и создайте снимок проекта.
2. Скачайте `rentgen-companion-0.1.20.vsix`, `SHA256SUMS` и `release.json`.
   Сверьте точный VSIX: `335890` байт,
   SHA-256 `b0d9ce0ac1efd11e1ef2a76e7a57fdd3b647ba55667fe079e86ea0e4a58244c9`.
3. Подготовьте новый отдельный профиль из полного checkout `5eee97ea050c9f4c06eaceb4d191f16868fb0141` по
   [инструкции адаптера](https://github.com/DmitrL-dev/1cai-public/blob/5eee97ea050c9f4c06eaceb4d191f16868fb0141/integrations/open-editor/README.md).
   Укажите Python именно установленного dev19, собственные registry/project ID,
   scanner, VSCodium и Cline. Генератор собирает Companion из соседних исходников;
   держите весь checkout на указанном commit.
4. Установите принятый VSIX через **Extensions: Install from VSIX…** в нужном
   отдельном доверенном профиле и проверьте версию 0.1.20.
5. Откройте сохранённый модуль, создайте ручную рабочую копию и сохраните
   новую версию отдельной командой. При прерывании сначала прочитайте прежнюю
   квитанцию по operation ID, не повторяйте изменяющую операцию вслепую.

Старый профиль не переключается на новый Python/Core автоматически.
Windows SID, права проекта и доверие workspace остаются обязательными.
Capture требует поддержанного scanner; модель и платформа 1С устанавливаются
отдельно и не нужны для первого ручного черновика по готовому снимку.

## Что этим не подтверждается

Новая активация в настоящем редакторе, native 1С business acceptance,
реальное задание модели, cold OwnerIPC и типовые конфигурации требуют
отдельной приёмки. Исторические результаты прежних версий не переименовываются.
Экспериментальный Linux state/ZIP/GUI Core не означает поддержку Companion
на Linux/macOS или готовность всего Linux-продукта. Полный Linux suite имеет
отдельный известный Windows baseline; он не является CI расширения.

Предыдущие теги, notes и assets 0.1.18 и других опубликованных версий
сохраняются без перезаписи. Новая поставка имеет собственные bytes и provenance.
