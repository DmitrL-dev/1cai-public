# Рентген companion 0.1.4 — предварительный выпуск

Расширение VSCodium для просмотра снимков и сохранённых черновиков. Добавлены
правка выбранного модуля локальной моделью Ollama, диагностика BSL до/после,
diff сохранённой ревизии, отмена и проверка результата после перезапуска.
Восстановление читает квитанции прежних операций, без повторного запроса модели.

Собственный код MIT; исходники, тесты, Python-адаптер и воспроизводимый сборщик
включены в VSIX. Для правки требуется отдельно установленное ядро
`rentgen-core 0.1.0.dev7`, подготовленный профиль, Ollama и закреплённый BSL runtime.
VSIX не устанавливает эти компоненты. Просмотр совместим с core dev4–dev7.

Проверены 22 теста расширения, 15 тестов генератора профиля и искусственный
пример в VSCodium с qwen3.5:9b: ревизия 2, чистый повторный и независимый BSL-анализ,
неизменный исходник и повторное открытие результата в новой сессии.

Это предварительный выпуск отдельного компонента. Чистая диагностика не
подтверждает бизнес-корректность произвольной правки. Тесты платформы 1С не
запускались, применение изменений отсутствует, Spectorn пока не подключён.
Подробности и ограничения находятся в README внутри VSIX.
