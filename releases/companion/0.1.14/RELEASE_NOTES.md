# Рентген Companion 0.1.14 — профили установленного Core dev14

Предварительный выпуск расширения редактора. Новая версия Core **0.1.0.dev14**
добавлена в явные списки совместимости. Настроенные профили не переключаются
автоматически; неизвестная версия и несовпадение профиля с установкой по-прежнему
вызывают отказ.

## Доступные версии по сценариям

| Сценарий | Явно принимаемые версии Core |
| --- | --- |
| Базовый профиль Companion | dev4–dev14 |
| Локальная правка и генератор отдельного профиля | dev7–dev14 |
| Платформенные проверки и тестовые профили | dev8–dev14 |

Версия не заменяет остальные проверки: профиль, разрешения, зарегистрированные
runtime и принадлежность выбранной ревизии продолжают проверяться.

Для новой установки используйте Core dev14, Companion 0.1.14 и новый отдельный
профиль по [инструкции адаптера](https://github.com/DmitrL-dev/1cai-public/blob/main/integrations/open-editor/README.md).
Генератор профиля записывает фактическую версию ядра после probe установленного
Python. В локальной проверке настоящий dev14 был принят; реестр проекта после
чтения сохранился побайтно.

## Что входит в изменение

Обновлены версия расширения, списки Core в командах редактора и включённом
Python-адаптере, текущие fixtures и документация. Ранее разрешённые версии
сохранены. Две новые параметризованные Node-проверки и две Python-проверки
включают dev14. Зависимости расширения не добавлялись.

До изменения списков обе новые Node-проверки получали `INVALID_EDITOR_PROFILE`.
В Python один из двух сценариев уже проходил, второй отвергал dev14.
После изменения прошли все 67 Node-тестов и 34 Python-теста профилей.

## CI и воспроизводимость

В [push CI](https://github.com/DmitrL-dev/1cai-public/actions/runs/36306417536)
и [PR CI](https://github.com/DmitrL-dev/1cai-public/actions/runs/36306421451)
каждый полный JUnit содержит **2443 теста**, без failures/errors/skipped.
В каждом прошли **67 Node-тестов**, Go, все **24 шага**, двойная сборка,
установленные CLI/MCP, snapshot comparison и observer. Все **440** ранее
принятых и новых локальных случаев найдены в каждом JUnit. Предварительные
ACL/runtime проверки входят в итоговый набор, не считаются второй раз.
Сверены GitHub digest скачанных архивов и реальные checkout из logs.
PR checkout `57d98daf5a7c050722d1c7d7fcfcb9290d05711b` имеет проверенных родителей и то же дерево
`23c6959b8f83eab760106f118ca70a6d4267c768`, что исходный commit. Квитанция приёмки исходного CI
публикуется в `docs/product/evidence/release-dev14-ci-20260927.json`.

Два локальных VSIX совпали побайтно. В обоих 39 записей, те же имена файлов;
изменённые записи точно соответствуют проверенной дельте исходников и версии
manifest. Расширение содержит собственные исходники, тесты и сборщик.
Сборка не использует npm или сетевой реестр.

## Настоящий editor → 1С → восстановление результата

Companion **0.1.14** с установленным Core **dev14** выполнил свежий сценарий
в отдельном профиле VS Code **1.139.1**, на 1С **8.3.27.2342** и YAxUnit **25.12**.
При актуальной ревизии 2 выбрана сохранённая ревизия 1. Baseline дал один
ожидаемый failure: ошибка записи не передавалась вызывающему коду. Candidate
прошёл тот же тест — один passed. Все **23 нативных шага** завершились с кодом 0.

Второй процесс редактора после отключения профиля прочитал тот же результат
без нового запуска. Прямой CLI повторно прочитал завершённую операцию, а новая
операция получила `TEST_PROFILE_DISABLED`. Все **909 файлов** завершённого
запуска сохранились побайтно; сохранены шесть исходных файлов, head и выбранный
proposal content ID. Модель не вызывалась.

В снимках до и после совпали все **2651 файл** отдельной закреплённой копии
редактора. Автообновление редактора и расширений отключено только в тестовых
user-data. Системные библиотеки и изменения между снимками этим не аттестованы.
Использован локальный wheel; его байты и все 103 файла установленного runtime
проверены на равенство принятой CI-поставке.
[Квитанция](https://github.com/DmitrL-dev/1cai-public/blob/main/docs/product/evidence/tests-editor-dev14-20260927.json),
SHA-256 `38a706e0a2cc38c99a615df671a708eb48b3bb9c5ec66d051adfd8d418ca8efa`.
Это испытание test/recovery на собственном синтетическом проекте; editor live
apply, типовые конфигурации и полная платформенная приёмка не заявляются.

## Границы

Нативный опыт ограничен своим синтетическим проектом, выбранной версией
платформы и отдельным профилем. Он не подтверждает типовые конфигурации,
editor live apply, полное бизнес-покрытие или защищённый маршрут модели.
Spectorn не интегрирован. Новое независимое peer review не выполнялось:
основной агент работал без субагентов. Production deployment не выполнялся.
