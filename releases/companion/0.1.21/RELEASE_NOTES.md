# Рентген Companion 0.1.21



Предварительный выпуск расширения для Windows-маршрута с Core **0.1.0.dev20**.
Готовность полного продукта, IDE, native 1С или AI этим компонентом не заявлена.

## Изменения после 0.1.20

- Рабочее место восстанавливает выбранный снимок, источник и черновик после
  перезапуска редактора; дерево метаданных строится через handles ядра;
  Problems привязаны к точной сохранённой ревизии, поздние ответы не
  подменяют изменившийся выбор.
- Команда **«Рентген: проверить сохранённый запуск тестов»** показывает досье
  повторной сверки retained YAxUnit artifacts с отчётом выбранной версии. Она
  появляется, только если установленный Core объявляет операцию
  `test-run-qualify`, ничего не запускает и не даёт права применения.
- Допуск версий Core задан одним явным списком; Core dev20 добавлен после
  квалификации пары, dev18 и неизвестные версии не допускаются.

Просмотр, сохранение и успешная проверка по-прежнему не разрешают применение
к рабочей базе или файлам выгрузки.

## Установка точной пары

1. Установите Core dev20 из `rentgen-core-0.1.0.dev20-windows-py311.zip`
   по его release notes, проверьте manifest/SHA-256 и создайте снимок проекта.
2. Скачайте `rentgen-companion-0.1.21.vsix`, `SHA256SUMS` и `release.json`.
   Сверьте точный VSIX: `477441` байт,
   SHA-256 `0c0d07b1ae9195d3a1a84d0d8467aa32fecc486aff6b900b04cd4387d5e08a4d`.
3. Подготовьте новый отдельный профиль из полного checkout `2a30f48799354fcef4bd57d1a03212fefa7f75fb` по
   [инструкции адаптера](https://github.com/DmitrL-dev/1cai-public/blob/2a30f48799354fcef4bd57d1a03212fefa7f75fb/integrations/open-editor/README.md).
   Укажите Python именно установленного dev20, собственные registry/project ID,
   scanner, VSCodium и Cline. Текст инструкции в этом commit ещё называет прежнюю
   пару; генератор профиля в том же commit явно допускает dev20. Генератор
   собирает Companion из соседних исходников; держите весь checkout на указанном commit.
4. Установите принятый VSIX через **Extensions: Install from VSIX…** в нужном
   отдельном доверенном профиле и проверьте версию 0.1.21.
5. Откройте сохранённый модуль, создайте ручную рабочую копию и сохраните
   новую версию отдельной командой. При прерывании сначала прочитайте прежнюю
   квитанцию по operation ID, не повторяйте изменяющую операцию вслепую.

Старый профиль не переключается на новый Python/Core автоматически.
Windows SID, права проекта и доверие workspace остаются обязательными.
Capture требует поддержанного scanner; модель и платформа 1С устанавливаются
отдельно и не нужны для первого ручного черновика по готовому снимку.

после публикации получат отдельную квитанцию в main; заранее успех не заявляется.

## Что этим не подтверждается

Человеческая приёмка клавиатуры/доступности, native 1С business acceptance,
реальное задание модели, cold OwnerIPC и типовые конфигурации требуют
отдельной приёмки. Экспериментальный Linux Core не означает поддержку Companion
на Linux/macOS или готовность всего Linux-продукта. Исторические результаты
прежних версий не переименовываются.

Предыдущие теги, notes и assets 0.1.20 и других опубликованных версий
сохраняются без перезаписи. Новая поставка имеет собственные bytes и provenance.
