# Рентген Companion 0.1.9 — профиль для core dev9

Этот выпуск расширения VSCodium добавляет поддержку установленного ядра
`rentgen-core 0.1.0.dev9`. Ранее опубликованный Companion 0.1.8 и его VSIX
остаются неизменными. Для нового ядра нужен новый профиль редактора, созданный
адаптером из текущего исходного коммита.

## Что изменилось

- Проверка профиля принимает core dev9. Версия установленного ядра по-прежнему
  сверяется с версией профиля; расширение не переключает Python или registry
  автоматически.
- Просмотр модулей и история черновиков работают с dev9. Локальная правка и
  сценарий ремонта доступны с dev7, dev8 и dev9. Проверка BSL, компилятор 1С
  и запуск сохранённой версии через зарегистрированный тестовый профиль
  доступны с dev8 и dev9.
- Команды редактора для нативных проверок и их контекстные элементы включаются
  для dev9. Повторное открытие результата читает сохранённую квитанцию и не
  запускает анализ или тесты снова.
- Адаптер профиля VSCodium/Cline и проверка установленного BSL runtime
  принимают dev9 при сохранении точного соответствия Python 3.11, MCP 1.30.0,
  registry и project ID.

## Совместимость и установка

Рекомендуемая пара: core `0.1.0.dev9` и Companion `0.1.9` на Windows x64,
CPython 3.11. Для просмотра поддерживаются также dev4–dev8; некоторые
команды доступны только в указанных выше версиях ядра. Установите проверенный
core в отдельное окружение, затем создайте профиль по
[инструкции редактора](https://github.com/DmitrL-dev/1cai-public/blob/main/integrations/open-editor/README.md) и
установите VSIX. Профиль связывает расширение с выбранным проектом и локальным
исполняемым Python.

Пакет собран воспроизводимым локальным сборщиком без npm-зависимостей.
SHA256 и размер VSIX зафиксированы в `manifest.json` и `SHA256SUMS`; workflow
повторно собирает и сверяет байты перед созданием GitHub Release.

## Границы выпуска

Это prerelease компонента. Нативные проверки и YAxUnit требуют отдельно
установленную платформу 1С и доверенный зарегистрированный профиль. Проверки
на типовых конфигурациях и полный продуктовый релиз пока не объявляются.
Расширение не публикует изменения напрямую в рабочую информационную базу и
не развёртывает фоновую службу или сетевой приёмник уведомлений.
