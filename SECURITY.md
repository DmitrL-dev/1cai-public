# Сообщить об уязвимости

Не публикуйте ключи, выгрузки заказчика или рабочие журналы в открытом issue.
Проверьте наличие **Report a vulnerability** во вкладке Security репозитория;
если приватный канал недоступен, создайте issue без деталей эксплуатации
с просьбой предоставить приватный канал связи. Срок ответа пока не гарантирован.

Опубликованный профиль, описанный в этом дереве, — core 0.1.0.dev15 /
companion 0.1.15, Windows x64 / Python 3.11. Исходники core 0.1.0.dev17 /
companion 0.1.18 остаются кандидатами; наличие исходников или отдельного
успешного теста не означает приёмку нового выпуска. Актуальный для выбранного
набора состав и ограничения сверяйте с [README](README.md) и
[матрицей готовности](docs/product/READINESS.md). Продукт находится в раннем доступе.
Хэши релизов проверяют целостность файлов; цифровой подписью они не являются.
Результаты BSL и локальные JSON-журналы не являются доверенным разрешением
на применение изменений. Границы доверия описаны в [архитектуре](ARCHITECTURE.md).
