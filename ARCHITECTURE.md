# Архитектура публичного ядра

| Модуль | Ответственность |
| --- | --- |
| `rentgen_core` | Проекты, права, публикация снимков, источники, черновики, квитанции; CLI и stdio MCP |
| `rentgen_graph` | Чтение графа и адаптер scanner |
| `go` | Scanner BSL, построение данных графа |
| `rentgen_diagnostics` | Проверка и запуск закреплённого профиля BSL Language Server |
| `integrations/open-editor` | Подготовка профиля и управление одной локальной правкой |
| `integrations/vscode-rentgen` | Просмотр снимков/версий и команды редактора |

Реестр выбирает проект; состояние проекта хранится отдельно от исходников.
Опубликованный снимок связывает точные байты источников и граф. SourceRef
идентифицирует источник внутри конкретного снимка. Чтение проверяет полномочия
и целостность; обновление head не меняет уже выбранный снимок.

Правки сохраняются в черновик. Запись сравнивает ожидаемую ревизию с текущей;
квитанция позволяет выяснить результат после потери ответа. Повторное чтение
квитанции не повторяет мутацию. Редактор получает состояние через публичный CLI,
агент — через ограниченный MCP. Доступы определяются ядром, а не инструкцией LLM.

Адаптер локальной модели формирует служебные запросы сам. Модель возвращает
замены текста, после которых запускается диагностика. Журнал диагностики —
неподписанное локальное свидетельство; он не является разрешением на применение.

Граница безопасности — доверенный Windows-пользователь и стартовые параметры.
Другие процессы того же SID и доверенные расширения не изолированы друг от друга.
Стандартный профиль не предоставляет агенту применение к живой конфигурации.

Подробные решения: [публикация](docs/product/SNAPSHOT-PUBLICATION-ADR.md),
[сессии чтения](docs/product/SNAPSHOT-READ-SESSIONS.md),
[состояние операций](docs/product/WORKFLOW-STATE-ADR.md),
[права](docs/product/PROJECT-ACCESS.md),
[локальная правка](docs/product/LOCAL-REPAIR-DESIGN.md).

В этом дереве нет старого HTTP-портала. Некоторые инструкции из исходной
поставки описывают его прежние контракты; они не означают наличие сервера
в текущем пакете. История экспериментального дерева доступна по ссылке в README.
