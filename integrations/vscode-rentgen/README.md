# Рентген: проект и черновики

Открывайте модули опубликованного снимка и сравнивайте сохранённые версии
черновиков в VSCodium. Разрабатываемое расширение 0.1.5 использует локальное ядро
**0.1.0.dev4–0.1.0.dev8**;
LLM, сеть и дополнительные npm-пакеты для просмотра не нужны. Собственный код MIT.

Запускайте подготовленный профиль через `launch.ps1`: он передаёт
`RENTGEN_EDITOR_PROFILE`. Python, реестр и проект берутся из этого профиля
один раз при запуске. Настройки workspace не выбирают исполняемые файлы.
Требуются Windows и доверие к рабочей папке; доступ к проекту проверяет ядро
по текущему SID при каждом новом чтении.

В проводнике редактора:

- **Рентген: модули** — поиск части пути во всём текущем снимке, открытие
  текста, следующая порция из 100 модулей. Кнопка обновления явно выбирает
  последний опубликованный снимок. Его короткий ID виден в панели и вкладке.
- **Рентген: черновики** — активные или архивные черновики, по 25 за порцию.
  Нажатие открывает сравнение выбранной версии с её исходным снимком.
  Раскройте черновик, чтобы выбрать старую версию; история также листается.
  После работы агента обновите дерево черновиков.

Открытые документы только для чтения. Переключение снимка не меняет уже
открытый текст и старые сравнения. Новое открытие заново читает ядро;
прочитанный ранее текст остаётся в открытых вкладках даже после отзыва прав.
Сохранение копии стандартными средствами редактора не применяет черновик.
Другие доверенные расширения могут менять буфер через API редактора, даже
когда обычный ввод заблокирован. Это не меняет снимок/черновик в ядре;
взаимная изоляция расширений здесь не обеспечивается.

Просмотр поддерживает строгий UTF-8, в том числе BOM, до 1 МиБ на документ.
Перед показом проверяются SourceRef, размер и SHA256. Другие кодировки и
более крупные модули дают явный отказ. В памяти ограничены очередь CLI
(8 запросов), документы (128), строки поиска (5000) и история (1000 версий
на раскрытый черновик); сузьте поиск или закройте лишние вкладки при достижении
предела. CLI имеет таймаут 30 секунд и ограничение вывода 2 МиБ.

`PROJECT_FORBIDDEN` означает отказ ядра: проверьте membership проекта.
`UNKNOWN_VIEW_HANDLE` — устаревшее выделение: повторно выберите строку.
`DOCUMENT_NOT_UTF8` и `DOCUMENT_SIZE_LIMIT` не заменяются обрезанным текстом.
При ошибке профиля исправьте его в доверенном месте и перезапустите редактор.

## Правка с локальной моделью

Для core **0.1.0.dev7** у строки модуля доступна кнопка «Правка с локальной
моделью». Введите имя установленной модели Ollama (предлагается `qwen3.5:9b`)
и задачу. Нужны работающий `http://127.0.0.1:11434` и установленный закреплённый
runtime BSL. Расширение включает исходники адаптера и запускает их Python из
профиля; установку моделей или runtime команда не выполняет.

Создаётся новый черновик, выполняются диагностика исходной ревизии, один запрос
модели, сохранение правки и повторная диагностика BSL. Открывается сравнение
подтверждённой ядром ревизии. Исходный модуль не меняется. Чистая диагностика
не доказывает правильность бизнес-логики: проверьте смысл изменения. Тесты 1С
и применение недоступны; Spectorn к этому адаптеру пока не подключён.

Кнопка остановки в уведомлении прекращает собственное дерево процессов.
После остановки или перезапуска редактора используйте «Рентген: проверить
результат правки» в палитре команд или панели черновиков. Команда читает
квитанции прежних операций и открывает найденную ревизию. Она не запускает
модель и не повторяет запись. Неопределённый результат требует повторной
проверки, а новый запуск правки создаст другой черновик.

Журнал, инструкция и предложение модели сохраняются в `repair-runs` внутри
профиля; они могут содержать код. Лимиты: полный модуль 32 КиБ, задача 4 КиБ,
модель 120 секунд / 4096 выходных токенов, весь процесс до 450 секунд.
Одновременные старты запрещены в одном экземпляре расширения. До 200 каталогов
запусков на профиль, автоматического удаления нет. Диагностика в локальном
JSON остаётся неподписанным свидетельством и не разрешает применение.
Полная готовность продукта этим компонентом не заявлена.

## Сборка

`python build.py --output NEW_FILE.vsix` создаёт детерминированный VSIX
стандартной библиотекой Python. Исходники, тесты, packager, README и MIT license
включены. `node --test test/*.test.cjs` запускает локальные проверки.
Генератор `integrations/open-editor/prepare.py` собирает этот же VSIX из
исходников и добавляет его в новый профиль; установщик проверяет SHA256.

Использованы публичные API [Tree View](https://code.visualstudio.com/api/extension-guides/tree-view),
[Virtual Documents](https://code.visualstudio.com/api/extension-guides/virtual-documents)
и [Workspace Trust](https://code.visualstudio.com/api/extension-guides/workspace-trust).

## Проверка в установленной 1С (core dev8)

В контекстном меню черновика или его версии выберите «Проверить версию в 1С»
и укажите полный `1cv8.exe`. Проверяется именно выбранная сохранённая версия
на её снимке. Открывается JSON-отчёт с раздельной диагностикой исходника и
черновика. Рабочая конфигурация не изменяется. Требуется одна выгрузка Designer
XML без расширений; функциональные тесты и применение в этом сценарии отсутствуют.

Команда «Результат проверки 1С» доступна в панели черновиков и палитре.
Выберите сохранённый запуск или введите UUID. Это только чтение: платформа,
предложение и исходные файлы для него не требуются. После ошибки запуска его
UUID остаётся в сообщении и в `platform-runs/<UUID>/request.json` профиля.
Отсутствие записи в ядре (`PLATFORM_RUN_NOT_FOUND`) означает, что ядро ещё не
подтвердило приём запроса, а `incomplete` — отсутствие конечного отчёта.
Ни один статус не вызывает повтор автоматически.

Проверка имеет предел 600 секунд внутри ядра, процесс редактора — 660 секунд.
Отмена останавливает принадлежащее запуску дерево процессов Windows. Аварийное
завершение самого редактора не гарантирует остановку дочерней 1С; `incomplete`
не показывает, жив ли процесс. История профиля ограничена 1000 записями.

0.1.5 пока является сборкой разработки. Опубликованная 0.1.4 сохранена отдельно.
Кнопка локальной правки по-прежнему требует dev7; на dev8 доступны просмотр,
черновики/MCP и проверка платформой, перенос управляемой правки ещё не принят.
