# Собственная конфигурация для проверки метаданных

Синтетический пример Рентгена, MIT; данных организаций и сторонних конфигураций нет.
Сгенерирован операциями EDT-MCP 2.16.1 в отдельном EDT 2026.1.3.

- `baseline`: конфигурация RentgenMD, язык Russian, справочник Products.
- `created`: добавлены строковый Article длиной 32 и основная форма ItemForm
  с полями Code, Description, Article.
- `renamed`: Article переименован в SKU с обновлением DataPath поля формы.
  Само поле сохранило имя Article; его данные теперь относятся к SKU.

`manifest.json` фиксирует точные байты. UUID намеренно одинаковы между поколениями:
это разные состояния одной конфигурации. Не импортируйте их как независимые
расширения и не считайте этот пример типовой конфигурацией.

Проверка на собственной новой базе описана в
[отчёте эксперимента](../../../docs/product/EDT-METADATA-EXPERIMENT.md).
Платформа 1С, EDT и плагин в эти исходники не включены.
