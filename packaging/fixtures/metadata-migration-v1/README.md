# Собственные данные для проверки миграции

MIT; сторонний код YAxUnit сюда не включён. Модуль устанавливается только в
тестовое расширение новой собственной ИБ, созданной из edt-metadata-v1.

Три записи проверяют Unicode, пустую строку и предельные 32 знака. Полная исходная
ссылка каждой записи сохраняется внутри тестовых данных: UUID без дефисов разбит
между Наименованием (25 знаков) и окончанием Кода (7). Префикс Кода различает
ожидаемые значения. Проверка сравнивает все 32 знака, число записей и значения;
методы чтения не перезаписывают данные.

Последовательность: создание → отдельное повторное чтение → нормализация EDT →
Article→SKU → возврат исходной схемы → отрицательный пример с другим UUID реквизита.
Это проверочный корпус собственной конфигурации, не общая квалификация миграций.

Для фикстуры с языком Russian адаптируется заимствованный язык тестового расширения
YAxUnit; базовые выгрузки остаются точными входами preview. Инструкции и границы
проверки — в docs/product/METADATA-MIGRATION.md.
