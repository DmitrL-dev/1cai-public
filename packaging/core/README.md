# Рентген: локальное ядро

Открытое ядро для исходников конфигурации 1С: снимки, граф, отдельные черновики,
история и результаты проверок. Лицензия MIT. **Ранний доступ.** Версия
`0.1.0.dev18` в этих исходниках — кандидат для разработки; опубликованная
пара Core dev15 / Companion 0.1.15 сохраняет собственные артефакты и приёмку.

## Начать с понятного результата

Первый результат — снимок готовой выгрузки и список модулей. Модель,
редактор и установленная платформа 1С для него не нужны. Нужны
Windows x64 / CPython 3.11, папка исходников и отдельный Go scanner.
Готовый Windows-комплект содержит scanner; один wheel его не содержит.

## Состав и границы

- `rentgen_core`: проекты, права, снимки, черновики, квитанции, CLI и stdio MCP.
- `rentgen_graph`: адаптер графа; Go scanner собирается отдельно.
- `rentgen_diagnostics`: закреплённые профили BSL Language Server.
- Базовый wheel не требует сторонних runtime-зависимостей. Optional extra
  `mcp` использует официальный SDK 1.30.0 и свой закреплённый профиль установки.

Java/BSL-LS, платформа 1С, EDT, модели, частные конфигурации и ключи не входят
в wheel. Старый HTTP-портал также не входит в поставку. Инструменты третьих
сторон распространяются на своих условиях.

Ядро хранит состояние отдельно от исходников. Черновик и его ревизии не
применяют изменение к рабочей базе. BSL, платформенная проверка и YAxUnit
требуют соответствующих установленных инструментов и профилей. Результат
проверки относится к выбранной ревизии и сам по себе не разрешает запись.

Ограниченные workspace, Designer XML и BSL live writers имеют отдельные
права, предусловия и recovery. Они не обещают универсальный откат базы или
защиту от любой одновременной внешней записи. Граф отражает ограниченный
статический анализ; бизнес-правильность и все зависимости им не доказываются.

Инструкции установки, доступа, миграции, MCP и проверок находятся в
`docs/product` внутри sdist. Полный каталог доступен в
[репозитории](https://github.com/DmitrL-dev/1cai-public/blob/main/docs/README.md).

## Платформы и развитие

Опубликованный полный маршрут рассчитан на Windows. Linux/macOS добавляются
по операциям: локальное состояние и чтение истории, затем безопасные адаптеры
снимков и процессов. Portable wheel не является доказательством поддержки
всех команд. Companion использует собственный Windows-профиль и проверяется отдельно.

Экспериментальный Rust input core уже реализует bounded ZIP import на Linux;
он поставляется отдельно от pure-Python wheel и требует явного executable hash.
Полная перепись и универсальное ускорение не заявлены. Приоритеты и критерии:
[дорожная карта](https://github.com/DmitrL-dev/1cai-public/blob/main/ROADMAP.md).

## Сборка из исходников

Используйте отдельное окружение и закреплённый профиль сборки из инструкции
`docs/product/CORE-INSTALLATION.md`. Backend — Hatchling, а не старый `setup.py`.

```text
python -m build --no-isolation
```

Wheel содержит выбранные Python-модули, runtime-профили и лицензию. Sdist
добавляет исходники Go scanner, lock-файлы и инструкции. Основная точка входа —
`rentgen`, также доступна `python -m rentgen_core`.

Новый пакет принимается по точному commit, составу, хэшам, установке и заявленным
сценариям. Исторические native-опыты, тесты синтетических проектов и наличие
API не подтверждают готовность к любой клиентской конфигурации.

## Экспериментальный source-facts CLI

Исходный пакет также содержит ограниченный Linux `source-facts`: готовый ZIP,
явные BSL entries и byte span проходят Rust input-core, отдельный Go lexical
observer и Rust source-only envelope. Итоговая приёмка этого маршрута pending;
receiver binding/runtime всегда unknown, XML profile только handwritten.
Три executable собираются отдельно и не входят в wheel. Команда не имеет MCP
endpoint или интерфейса Companion.
