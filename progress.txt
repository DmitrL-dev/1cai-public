## Codebase Patterns

### Micro-Swarm Architecture
- `engine.py` — scalar autograd (Value + backward)
- `model.py` — MicroModel (micro-transformer, Adam, save/load JSON weights)
- `domains.py` — DomainConfig + FeatureSpec + extractor functions
- `bsl_domains.py` — BSL-ориентированные домены (Phase 3.5)
- Паттерн домена: keyword regex → numeric features → normalize → MicroModel → score
- Каждый домен = 8 фич, отдельный extractor

### BSL Parser
- `src/ai/agents/code_review/bsl_parser.py` — regex-based, извлекает функции/процедуры/переменные/запросы
- Cyclomatic complexity через подсчёт Если/Для/Пока/Попытка

### Testing
- pytest с `--no-cov` для быстрого прогона
- testpaths = tests/
- Тесты BSL domains: `tests/unit/test_bsl_domains.py`

### Git
- Conventional commits: `feat:`, `fix:`, `cleanup:`
- Ветка: main

### Go Scanner
- `go/internal/extractor/` — regex-based BSL feature extraction (Cyrillic: `(?:^|\s)` вместо `\b`)
- `go/internal/scanner/` — parallel WalkDir + goroutines fan-out
- `go/cmd/bsl-scan/` — CLI: json/summary, -workers, -min-loc
- `src/micro_swarm/go_bridge.py` — Python subprocess → Go → JSON → SwarmRouter
